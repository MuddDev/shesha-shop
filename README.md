# 🧺 SheshaShop — Nuxt 4 + Shopify + SCSS

**SheshaShop** — це storefront для рушників і текстилю преміум-класу, створений на базі **Nuxt 4**, **Shopify Storefront API**, і **SCSS**.

---

## ⚙️ Технології

- **Nuxt 4**
- **Shopify Storefront API (GraphQL)**
- **Pinia** — керування станом (кошик, wishlist)
- **SCSS** — стилізація без Tailwind
- **@nuxt/content** — контент (FAQ, сторінки, homepage layout)
- **@nuxt/image** — оптимізація зображень
- **@nuxt/scripts** — підключення аналітики та пікселів
- **@nuxt/fonts** — шрифти

---

## 🚀 Як запустити

```bash
npm install
npm run dev
```
